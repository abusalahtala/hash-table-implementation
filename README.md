CSE 331 Project 3 - Hash Tables

This project is about implementing a hash table in Python using double hashing to handle collisions.

The hash table supports inserting, deleting, and searching for values. It also resizes when the table gets too full.

The project also includes two other functions:

display_duplicates() - finds duplicate images using their hash values, including rotated versions.

generate_fan_chant() - finds starting positions where different arrangements of given words appear in a string.

All the code is in solution.py.
